Console Matrix Animation with Custom Containers

Консольное приложение на C++ (Windows, WinAPI), реализующее анимацию падающих линий в стиле Matrix
с поддержкой взрывов, случайных ASCII-символов, цветных эффектов
и самописных шаблонных контейнеров.

Проект является улучшенной версией лабораторной работы и демонстрирует применение:

объектно-ориентированного программирования,

абстрактных классов,

наследования,

шаблонов,

собственной реализации контейнеров данных.

📌 Основные возможности

Падающие вертикальные линии из случайных ASCII-символов

Генерация нескольких линий в секунду

Управляемая скорость движения

Эффект взрывов линий с расширяющимся радиусом

Epilepsy mode — случайный цвет объектов

Корректная работа при изменении размеров окна консоли

Самописные контейнеры вместо STL (vector, list)

▶️ Режимы запуска
🔹 Интерактивный режим
matrix.exe


Программа последовательно запросит:

частоту появления линий,

скорость движения,

длину линии,

вероятность взрыва,

минимальный и максимальный радиус взрыва,

режим цвета (Y / N).

🔹 Режим командной строки
matrix.exe <frequency> <velocity> <length> <explosionProbability> <minExplosionRadius> <maxExplosionRadius> <Y|N>


Пример:

matrix.exe 3 20 8 250 2 6 Y

🔹 Справка
matrix.exe --help
matrix.exe /?

⚙️ Параметры
Параметр	Описание
frequency	Количество линий в секунду (1–30)
velocity	Скорость движения линии (1–30)
length	Длина линии в символах
explosionProbability	Вероятность взрыва (1–1000)
minExplosionRadius	Минимальный радиус взрыва
maxExplosionRadius	Максимальный радиус взрыва
Y / N	Включение / выключение epilepsy mode
🧱 Архитектура проекта
🔹 Основные классы
Класс	Назначение
app_manager	Управление параметрами, генерацией линий и основным циклом
myLine	Логика движения линии и её взрыва
Explosion	Анимация взрыва

📦 Самописные контейнеры

В проекте не используются стандартные контейнеры STL для хранения данных.
Вместо них реализованы собственные шаблонные контейнеры:

🔸 List<T> (абстрактный класс)

Базовый интерфейс контейнера

Определяет:

push_back

insert

remove

size

🔸 LinkedList<T>

Двусвязный список

Аналог std::list

Используется для:

хранения активных линий,

хранения взрывов,

хранения координат символов линии

🔸 ArrayList<T>

Динамический массив

Аналог std::vector

Используется для:

хранения временных меток (мс),

генерации расписаний движения и взрывов

🎨 Визуальные эффекты

Каждый символ — случайный печатный ASCII-символ (!–~)

Цвет:

зелёный (обычный режим),

случайный (epilepsy mode)

Взрыв — расширяющийся ромб с цветной анимацией

Анимация бесконечна (завершается закрытием консоли)

🛠 Используемые технологии

C++

WinAPI (Windows.h)

Шаблоны

Абстрактные классы

Наследование

Консольная графика

📌 Примечания

Проект предназначен только для Windows

Используется GetTickCount64() для управления временем

Корректно реагирует на изменение размеров окна консоли

Не использует std::vector, std::list и другие STL-контейнеры

🎓 Учебное назначение

Проект выполнен в рамках лабораторной работы и демонстрирует:

разработку собственных контейнеров данных,

применение ООП на практике,

работу с консольной графикой и временем.
